# Logos de SAMPRE

## Ubicación
Coloca los logos de SAMPRE en esta carpeta.

## Nombres sugeridos

### Logo Principal
- **Nombre**: `sampre-logo.png` o `sampre-logo.svg`
- **Uso**: Header, Hero section
- **Dimensiones recomendadas**:
  - SVG (preferido) - escalable
  - PNG: 200x200px (transparente)
- **Formato**: SVG o PNG con fondo transparente

### Logo Alternativo (si aplica)
- **Nombre**: `sampre-logo-alt.png` o `sampre-logo-white.png`
- **Uso**: Footer (si el fondo es oscuro)
- **Dimensiones**: 200x200px
- **Formato**: SVG o PNG con fondo transparente

## Dónde se usan los logos

### 1. Header (navegación)
Archivo: `components/Header.jsx`
Reemplaza el placeholder actual (círculo con "S")

### 2. Footer
Archivo: `components/Footer.jsx`
Reemplaza el placeholder del logo

## Cómo actualizar después de agregar

Una vez que coloques tus logos aquí, avísame y actualizaré automáticamente:
- El Header para mostrar tu logo principal
- El Footer para mostrar tu logo
- La configuración de imágenes si es necesario

## Optimización

- **SVG**: Formato ideal para logos, escalable sin pérdida de calidad
- **PNG**: Si usas PNG, asegúrate de que tenga fondo transparente
- **Peso**: Mantener bajo 100KB si es PNG

## Ejemplo de nombres finales
```
/public/images/logos/
  ├── sampre-logo.svg          (logo principal)
  └── sampre-logo-white.svg    (logo blanco para fondo oscuro)
```
